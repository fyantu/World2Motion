World2Motion — Offline Video Supplement

Extract the entire ZIP archive, then open index.html in a modern desktop browser (Chrome, Edge, Firefox or Safari). No server or internet connection is required. Keep media/, posters/ and inputs/ next to index.html.

Use Play pair, Pause pair and Resume pair to control paired videos. The method comparison and ablation selectors work offline.
